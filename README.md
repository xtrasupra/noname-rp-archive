# NoName RP · Личный архив старого мода

![NoName RP · Личный архив старого мода — превью](preview.jpg)

Личный архив старого мода для **RAGE MP**, с которым мы работали в команде. Сохраняю его для себя как историю разработки и накопленного опыта.

[Открыть демо](https://xtrasupra.github.io/noname-rp-archive/) · [Исходный код](https://github.com/xtrasupra/noname-rp-archive)

## О проекте

Основное внимание в работе над этим модом уделялось игровым системам: серверной логике, клиентским событиям, хранению данных и взаимодействию модулей. Интерфейсы были вторым планом — они помогали проверять и связывать игровые сценарии, а их визуальную доработку мы планировали на более поздний этап.

Затем мы приняли решение продолжить работу с новым проектом, который уже находится на стадии открытого бета-тестирования (**OBT**). Этот старый мод я сохраняю для себя как личный архив: к нему можно вернуться, чтобы вспомнить решения, разобрать системы и проследить ход нашей работы.

**NoName RP** — нейтральное название этого архива. Он отражает рабочее состояние старого мода на тот момент.

## Основные системы

| Область | Модули в `packages/twinkle/` | Что можно изучить |
|---|---|---|
| Аккаунт и персонаж | `auth, characters, systems/character` | Авторизация, регистрация, выбор персонажа и спавна. |
| Транспорт | `systems/vehicle, systems/vehicleDealership, systems/rentcar, systems/lsc` | Состояние и владение транспортом, автосалон, аренда и тюнинг. |
| Имущество и экономика | `systems/house, systems/condos, systems/business` | Дома, квартиры, бизнесы и связанные сценарии взаимодействия. |
| Инвентарь и документы | `systems/inventory, systems/documents, systems/licenses` | Предметы, использование документов и лицензии. |
| Работы и активности | `systems/jobs, systems/fishing, systems/hunting, systems/quests` | Игровые работы, рыбалка, охота и задания. |
| Фракции и администрация | `systems/fractions, systems/governmentComputer, systems/admin, systems/adminBridge` | Фракционные интерфейсы, государственный компьютер и инструменты модерации. |
| Интерфейсы и связь | `systems/hud, systems/chat, systems/voice, systems/radialMenu` | HUD, чат, голосовые события и радиальное меню. |
| Хранение данных | `database` | Подключения, начальная подготовка и согласование структуры MySQL. |

## Структура

```text

scripts/           Вспомогательные инструменты

```

## Вспомогательная демонстрация интерфейсов

На GitHub Pages открывается обзор основных систем. Экраны интерфейсов оставлены как вспомогательная иллюстрация их взаимодействия; визуальная полировка не была приоритетом этого этапа. Витрина использует тестовые данные интерфейса. Сервер RAGE MP, игровая карта, базы данных и интеграции в браузере не запускаются. Некоторые игровые действия доступны только в соответствующем окружении.

Для локального просмотра интерфейсов:

```bash
cd frontend
npm ci
npm run dev
```

Для обновления опубликованной витрины: `npm run build:demo` из `frontend/`.

## Состав публикации

Сохранены исходники серверных систем, клиентских обработчиков, CEF, вспомогательных сценариев и структура БД. Исключены зависимости `node_modules`, вложенная Git-история, локальные `.env`, записи баз и их дубли, временные файлы, готовые серверные исполняемые файлы, библиотеки среды RAGE MP и игровые ресурсы.

Это ознакомительный архив исходников. Для запуска отдельного тестового сервера потребуются совместимая среда RAGE MP, собственные настройки, зависимости и недостающие игровые ресурсы. Шаблоны `.env.example` и `conf.example.json` помогают понять ожидаемое окружение.

## Навигация

Начать знакомство удобно с `packages/twinkle/index.js`, `packages/twinkle/bootstrap.js`, `frontend/src/app/bootstrap.ts` и `frontend/src/apps/index.ts`. Дальше можно проследить конкретную систему от серверного модуля до клиентского события и экрана.

## Участие и авторство

В работе над старым модом участвовал Бехтеев Д. Н. ([xtrasupra](https://github.com/xtrasupra)). Репозиторий показывает системы, с которыми мы работали, и сохраняет контекст совместной разработки. Наличие модуля в архиве не означает единоличное авторство каждого его фрагмента.

Имена авторов и сведения об источниках, присутствующие в исходных материалах, сохранены. Логотипы прежнего оформления удалены; служебные имена модулей, событий и таблиц оставлены для совместимости архивного кода. Графика, шрифты и игровые обозначения могут принадлежать их правообладателям. Публикация не меняет права на сторонние материалы.


## Проверки подготовленного архива

- Браузерное демо и обычная CEF-сборка проходят Vite и проверку TypeScript.
- 118 существующих серверных тестов проходят после установки зависимостей и сборки CEF.
- 30 статических проверок связки автошколы и работы дальнобойщика проходят.
- Восемь экранов витрины проверены в браузере; подключение к игровому серверу для их просмотра не требуется.

Для воспроизведения тестов сначала установите зависимости в корне и в `frontend/`, затем выполните `npm --prefix frontend run build`. Например, в PowerShell:

```powershell
$tests = Get-ChildItem packages -Recurse -File -Filter '*.test.js' | Select-Object -ExpandProperty FullName
node --test @tests
node scripts/verify-trucker-driving-school.js
```


## Экраны компьютеров

Интерфейсы сохраняют исходное оформление. Размеры, заданные относительно высоты окна, дополнительно ограничены его шириной: меню помещаются и на широкоформатных мониторах, и на экранах 1280×1024. Проверены восемь демонстрационных экранов на шести разрешениях от 1366×768 до 3440×1440. Небольшая кнопка ↩ возвращает к обзору архива.
