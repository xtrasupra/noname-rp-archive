# Подготовка публичного архива

Публикуется очищенная копия исходного рабочего билда. Локальный оригинал не удалён.

- Исходники интерфейсов собраны в `frontend`, ссылки сборки обновлены.
- Сохранены серверные исходники, клиентские события, CEF-исходники, тесты и вспомогательные сценарии.
- SQL содержит только `CREATE TABLE`; строки аккаунтов, логов и игровые записи не копировались.
- `.env`, готовые бинарные файлы сервера, карты/игровые ресурсы, зависимости, кэши и старые сборки не включены.
- Для GitHub Pages добавлен отдельный режим сборки `demo`. Обычная CEF-сборка сохраняет собственный выходной каталог.
- Наличие интерфейса в витрине показывает его браузерное представление и тестовые данные; полноценную игровую систему необходимо изучать в исходниках.

- Для личного архива выбрано нейтральное название NoName RP. Логотипы прежнего оформления удалены из исходников и опубликованных ресурсов. Основной акцент описания — игровые системы и переход команды к новому проекту на OBT.
